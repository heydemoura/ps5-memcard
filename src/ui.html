SETTINGS
Memory cards: a drive with a /memcard folder is a card, and saves go to every card that is plugged in. With no card around, the first drive becomes one. Other drives are left alone until you press Use as card.
Quiet time is how long a save must sit unchanged before it is copied. In-game gap limits how often the same save is copied while its game is running; when the game closes it is copied right away.
